# Quick-Rename-Tool
This tool helps you to quickly rename file
Simple instructions for using this software
Firstly, the folder you have selected cannot contain any folders
1. Add Name Mode: Click on the selection box and choose whether to add content at the beginning or end of the file name. Enter the specific content to be added in the input box to modify it.
2. Number arrangement mode: After clicking to modify, the software will automatically arrange the file according to 1, 2, 3... After arranging the numbers, you can choose the following reference indicators: by creation time, by file size. You can choose to sort from new to old or from old to new when created, or by size, from small to large or from large to small. The arrangement can arrange the file names in the selected way and order into 1, 2, 3...
The content mentioned above may not read smoothly because I am using a translation software, and this tool is still updating other content, which may not be complete.
